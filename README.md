# Mini Copilot — site public

Ce dépôt contient la page publique de présentation et une démo de chat sans moteur IA réel. Le code de l’application complète est conservé dans le dépôt privé séparé.

Le produit Mini Copilot est entièrement gratuit et ne propose aucun abonnement, paiement ou checkout. Les dépôts et le code source restent privés et propriétaires.

node --check app.js
